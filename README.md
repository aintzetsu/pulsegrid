# PulseGrid

Client-side 16-step drum sequencer and polyphonic Web Audio synthesizer with zero audio assets.

## Highlights
- 5 synthesized voices (`Kick`, `Snare`, `Hi-Hat`, `Bass Synth`, `Chord Stab`) powered by lookahead Web Audio scheduling.
- Accent hits (`Shift+Click` / right-click), track `Mute` / `Solo`, groove `Swing`, `Tempo`, resonant `Lowpass Cutoff`, and waveshaper `Warm Drive`.
- Live `<canvas>` time-domain oscilloscope, curated pattern presets, groove randomizer, `localStorage` persistence, and JSON pattern export.
